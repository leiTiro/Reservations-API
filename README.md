**Hotel Booking API – README**

1. **Overview**

This API powers an AI-driven hotel booking assistant. It allows an AI agent to create, view, modify, and cancel hotel bookings through structured HTTP endpoints. The API is designed to be easily integrated with conversational AI platforms (e.g. ElevenLabs agents) and automation tools.

2. **Key Features**

Create hotel reservations

Retrieve booking details

Modify existing bookings

Cancel bookings

Lightweight and fast REST API

AI-friendly JSON request/response structure


3. **Tech Stack**

Python (Flask)

SQLite (persistent storage)

RESTful API design

JSON-based communication
